# 📱 Facebook App UI

A modern **Facebook App UI Clone built with Flutter**, designed to recreate the look and feel of the Facebook mobile application. This project focuses on clean UI design, responsive layouts, and reusable Flutter widgets.

## ✨ Features

* 🏠 Home Feed UI
* 👤 Profile Screen
* 🔍 Search UI
* 🔔 Notifications UI
* 💬 Messenger / Chat UI
* 👥 Friends Section
* 📸 Create Post UI
* ❤️ Like, Comment & Share UI
* 📱 Responsive Design
* 🎨 Clean and Modern Interface

## 🛠️ Technologies Used

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android Emulator or Physical Device

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/facebook-app-ui.git
```

Navigate to the project:

```bash
cd facebook-app-ui
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
